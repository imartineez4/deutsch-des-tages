# Deutsch des Tages · website

The support page and privacy policy for the Deutsch des Tages iPhone app,
published with GitHub Pages.

- `index.html`: support page and contact
- `privacy/index.html`: privacy policy, generated from the app's
  `PrivacyPolicy.md` with `python3 tools/policy_to_html.py <PrivacyPolicy.md> privacy/index.html`.
  Regenerate it whenever the policy changes, so the site matches the app.

The Fraunces font in `fonts/` is licensed under the SIL Open Font License 1.1
(see `fonts/OFL.txt`).
